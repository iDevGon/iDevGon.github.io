# New Article

블로그 아티클을 새로 작성하는 스킬입니다.

## 실행 절차

### 1. 기존 글 분석

먼저 `apps/blog/src/articles/` 디렉토리의 기존 글들을 모두 읽어서 문체, 톤, 구조 패턴을 파악합니다.

- 어투 (존댓말/반말, 격식/비격식)
- 문단 구성 방식
- 코드 블록, 인용문, 목록 등의 사용 패턴
- frontmatter 형식 (title, author, date, tags)

### 2. 사용자 입력 받기

인자가 주어지지 않은 경우, AskUserQuestion 도구로 아래 내용을 질문합니다:

- **주제**: 어떤 내용의 글을 쓸 것인지 (예: "React Server Components 소개", "TypeScript 제네릭 활용법")
- **태그**: 글에 붙일 태그 (예: React, TypeScript)

인자가 주어진 경우 해당 내용을 주제로 사용하되, 태그는 주제에서 유추하거나 사용자에게 확인합니다.

### 3. 글 작성

아래 규칙을 따라 글을 작성합니다:

#### frontmatter 형식

```yaml
---
title: 글 제목
author: DevGon
date: YYYY-MM-DD (오늘 날짜)
tags:
  - 태그1
  - 태그2
---
```

#### 파일명 생성 규칙

- 제목을 기반으로 영문 slug를 생성합니다.
- 한글 제목인 경우 의미를 살린 영문 번역으로 slug를 만듭니다. (예: "AI 시대와 개발자" → `developers-in-the-ai-era`)
- 영문은 소문자로 변환합니다.
- 공백과 특수문자는 하이픈(`-`)으로 대체합니다.
- 연속된 하이픈은 하나로 합칩니다.
- 앞뒤 하이픈은 제거합니다.
- 확장자는 `.md`입니다.

#### 본문 작성 규칙

- 기존 글들의 문체와 톤을 최대한 따릅니다.
- 실질적이고 유용한 내용을 담습니다.
- 적절한 소제목(`##`, `###`)으로 구조화합니다.
- 기술 글의 경우 코드 예시를 포함합니다.
- 최소 300자 이상의 본문을 작성합니다.

### 4. 파일 저장

`apps/blog/src/articles/{slug}.md` 경로에 파일을 생성합니다.

동일한 파일명이 이미 존재하면 사용자에게 알리고 덮어쓸지 확인합니다.
