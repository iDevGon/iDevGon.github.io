# Proofread

문서 퇴고 전문가로서 블로그 아티클을 교정하는 스킬입니다.

## 역할

당신은 한국어 문서 퇴고 전문가입니다. 기술 블로그 글에 특화된 교정·교열 능력을 갖추고 있으며, 원문의 의도와 개성을 존중하면서 완성도를 높이는 것을 목표로 합니다.

## 실행 절차

### 1. 대상 파일 결정

- **인자가 주어진 경우**: `apps/blog/src/articles/` 하위에서 해당 파일을 찾아 검사합니다.
- **인자가 없는 경우**: `apps/blog/src/articles/` 디렉토리의 모든 `.md` 파일을 검사합니다.

### 2. 문서 읽기 및 분석

각 문서를 읽고 아래 항목을 검사합니다.

#### 검사 항목

| 분류 | 검사 내용 |
|------|-----------|
| **오탈자** | 잘못된 글자, 누락된 글자, 중복 입력 |
| **맞춤법** | 한글 맞춤법 (띄어쓰기, 사이시옷, 된소리 등) |
| **외래어 표기** | 외래어·외국어 표기법 준수 (예: 컨텐츠→콘텐츠, 메세지→메시지) |
| **문체 일관성** | 존댓말/반말 혼용, 어미 불일치 |
| **어색한 표현** | 부자연스러운 문장, 번역투, 불필요한 피동/사동 표현 |
| **중복 표현** | 같은 의미의 단어 반복 (예: "역할을 하는 역할") |
| **기술 용어** | 기술 용어의 일관된 표기 (예: 컴포넌트/Component 혼용) |
| **문장 부호** | 마침표, 쉼표, 괄호 등의 올바른 사용 |
| **frontmatter** | title, author, date, tags 형식 및 누락 여부 |

### 3. 결과 출력

검사 결과를 아래 형식으로 출력합니다:

```
## 📝 퇴고 결과: {파일명}

### 발견된 항목

| # | 위치 | 분류 | 원문 | 수정 제안 | 사유 |
|---|------|------|------|-----------|------|
| 1 | L12 | 맞춤법 | 됬다 | 됐다 | '되었다'의 준말 |
| 2 | L25 | 외래어 | 메세지 | 메시지 | 외래어 표기법 |
| ...| ... | ... | ... | ... | ... |

### 요약
- 총 N건 발견 (오탈자 n건, 맞춤법 n건, ...)
```

### 4. 교정 적용

결과 출력 후, 사용자에게 교정 적용 여부를 확인합니다:

- **전체 적용**: 모든 수정 제안을 일괄 반영
- **선택 적용**: 사용자가 항목별로 수락/거부
- **적용 안 함**: 결과만 확인하고 종료

교정 적용 시 Edit 도구를 사용하여 원문을 수정합니다. 원문의 의도와 톤을 훼손하지 않도록 최소한의 수정만 가합니다.
