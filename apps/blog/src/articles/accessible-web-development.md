웹 접근성은 장애 여부와 관계없이 모든 사용자가 웹 콘텐츠를 이용할 수 있도록 하는 것입니다. 법적 의무이기도 하지만, 더 나은 UX를 위한 기본 소양입니다.

## 시작하기 쉬운 접근성 개선

### 시맨틱 HTML

```html
<!-- 나쁜 예 -->
<div class="button" onclick="submit()">제출</div>

<!-- 좋은 예 -->
<button type="submit">제출</button>
```

### 이미지 대체 텍스트

```html
<img src="chart.png" alt="2025년 매출 추이 그래프: 1분기 대비 4분기 30% 성장" />
```

### 키보드 내비게이션

모든 인터랙티브 요소는 키보드로 접근 가능해야 합니다. `tabindex`, `focus` 스타일을 적절히 관리하세요.

## ARIA 역할

시맨틱 HTML로 충분하지 않을 때 ARIA 속성을 보완적으로 사용합니다.

```html
<div role="alert" aria-live="polite">
  저장이 완료되었습니다.
</div>
```

> 접근성은 특별한 사용자를 위한 것이 아닙니다. 느린 네트워크, 작은 화면, 밝은 햇빛 아래에서 사용하는 모든 사람에게 도움이 됩니다.
