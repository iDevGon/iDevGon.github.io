# Resume Data 작성 원칙

`resume.json` 을 수정할 때 아래 원칙을 따른다.

1. **비즈니스 문제 → 기술 해결 → 결과** 구조로 서술한다. 단순 기술 나열이 아니라, 어떤 비즈니스 문제가 있었고 어떻게 해결했으며 어떤 성과가 나왔는지를 중심으로 작성한다.
2. **경력은 최신순**으로 정렬한다. `experiences` 배열과 각 회사의 `projects` 배열 모두 최근 항목이 먼저 온다.
3. **프로젝트는 임팩트 순**으로 정렬한다. 해결한 문제의 크기, 비즈니스에 미친 영향이 큰 것부터 작성한다.
4. **depth를 두지 않는다.** 접기/펼치기, 외부 페이지 연결 등으로 정보를 숨기지 않는다. 모든 내용은 한 페이지에서 바로 확인할 수 있어야 한다.
5. **직무 관련 경험만 포함한다.** 프론트엔드 개발과 무관한 경험은 제거한다.
6. **본인을 드러낼 수 있는 링크를 첨부한다.** 코드(GitHub PR, 오픈소스 기여 등)나 블로그 글 링크를 적극 활용한다.
